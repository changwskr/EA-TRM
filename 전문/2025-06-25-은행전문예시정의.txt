### 채널 유형별 특성
```
ATM:
- 24시간 운영
- 현금 입출금 가능
- 카드 인증 필수
- 오프라인 처리 가능

MOBILE:
- 개인 인증 필수
- 푸시 알림 지원
- 생체 인증 가능
- 위치 기반 서비스

WEB:
- 브라우저 기반
- 세션 관리 중요
- SSL/TLS 필수
- 다중 탭 지원

POS:
- 가맹점 전용
- 카드 결제 전용
- 영수증 출력
- 통신 이중화
```

### 인증 레벨 정의
```
L1 (기본): 
- ID/PW 인증
- 기본 조회 기능
- 소액 거래 (10만원 이하)

L2 (중급):
- 2차 인증 (OTP, SMS)
- 일반 이체 기능  
- 중간 거래 (100만원 이하)

L3 (고급):
- 공인인증서/생체인증
- 고액 거래 무제한
- 관리자 기능 접근
```

## 11. 테스트 시나리오

### 정상 케이스
- 계좌 조회: 유효한 계좌번호로 조회
- 계좌 이체: 충분한 잔액으로 이체
- 카드 승인: 유효한 카드로 승인 요청

### 오류 케이스
- 계좌 조회: 존재하지 않는 계좌번호
- 계좌 이체: 잔액 부족 상황
- 카드 승인: 정지된 카드로 승인 요청

이 설계서는 실제 금융권에서 사용하는 전문 구조를 JSON 형태로 현대화한 것입니다. 보안, 성능, 확장성을 모두 고려하여 설계되었습니다.
